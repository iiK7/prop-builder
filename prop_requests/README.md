# prop_requests

Upload an image (`.png`, `.jpg`) or a model (`.glb`) here to build a FiveM prop.

- The file name becomes the prop name: `estate_sofa_01.png` builds `estate_sofa_01`.
- To set the real height, add `@<metres>` before the extension: `estate_sofa_01@0.9.png`.

The result is attached to the "Prop builder" run in the Actions tab and copied to the
`prop-builds` branch under `builds/<name>/`.
