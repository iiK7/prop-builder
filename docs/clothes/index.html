الإعداد: مفتاح GitHub
  1. افتح صفحة إنشاء المفتاح
  2. Repository access ← Only select repositories ← اختر prop-builder و claude-private (الاثنين: GitHub ما يسمح يتحددون من الرابط، فاختارهم بنفسك)
  3. Permissions: Contents = Read and write، و Actions = Read
  4. Generate token، وانسخه والصقه هنا

نفس مفتاح صفحة البروبز، بس لازم يشمل الريبو الخاص claude-private بعد: هناك تنرفع الباكات وتنحفظ النتائج (الباكات المدفوعة ما تنرفع للريبو العام أبداً). بدون تذكير: ينحفظ لهالجلسة بس. لا تعلّم عليه بجهاز مو لك، ولا تلصق المفتاح بأي محادثة.
